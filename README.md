# Thanithpol Thiramongkolchai — Portfolio

Modern personal portfolio built for Vercel with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS 4**.

## Stack

- Next.js 16.2.11 (App Router)
- React 19.2
- TypeScript
- Tailwind CSS 4.3.3
- Lucide React
- Vercel

## Structure

```text
app/
  layout.tsx
  page.tsx
  globals.css
components/
  navbar.tsx
public/
package.json
next.config.ts
postcss.config.mjs
tsconfig.json
vercel.json
```

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. The project is configured for Next.js and uses the standard `npm run build` command.
